# well

A **well** (井戸) is any folder the user picks. Inside it three sections — notes,
wiki, tasks — live as plain markdown, with only rebuildable config and cache under
`.ido/`.

Folders inside the wiki are cosmetic. A page's slug is globally unique, so moving
this page into another folder would not break a single link pointing at it.

See also [[block-editor]] and [[mcp-server]].
